# 南大选课冲突过滤器

修复了南大选课网站的过滤冲突功能，自然地融入网站交互！

## 功能

- 自动读取已选课程，无需手动录入
- 支持单双周、连续周次等时间格式
- 配合页面“过滤冲突”自动隐藏冲突课程
- 课程列表刷新后自动重新过滤

## 安装

1. 下载本项目 ZIP 并解压
2. 浏览器打开 `chrome://extensions`（或 `edge://extensions`）
3. 开启右上角“开发者模式”
4. 点击“加载已解压的扩展程序”，选择项目文件夹

## 使用

1. 登录 xk.nju.edu.cn 选课系统并进入选课页面
2. 点击页面上的“过滤冲突”按钮
3. 冲突课程会被自动隐藏

## 说明

- 仅在 xk.nju.edu.cn 选课页面生效
- 代码只在浏览器本地运行，不上传个人数据
- 仅供选课参考，与南京大学官方无关
